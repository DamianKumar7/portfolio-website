## Design Specificity Verdict

Authored for this product, not category-interchangeable — but the terminal metaphor is load-bearing only at the hero and in the section chrome; below the fold it thins to a decorative eyebrow font over conventional cards. Real design system (BezelCard, eyebrow tag, button-in-button, shared easing) = genuine authorship. Structure is still the default portfolio spine.

## What's Working
1. A real, disciplined design system — coherence across all seven sections; strongest seniority signal.
2. Every claim carries a number, front-loaded (500+, $30M/yr, 10M+, 70%, sub-5ms).
3. Terminal metaphor restrained, not neon-hacker — differentiates without costing credibility.

## Priority Issues
[P1] Hero role line buries backend seniority / over-indexes AI. Typewriter gives AI equal terminal billing; eyebrow says "Senior / AI Engineering." Contradicts PRODUCT positioning (backend leads). Fix: pin static "Senior Backend / Distributed Systems Engineer", demote typewriter. Command: clarify.

[P1] JS animations ignore prefers-reduced-motion. CSS block only covers CSS; framer-motion entrances + react-type-animation run regardless. Fix: useReducedMotion() gate + static role line. Command: harden.

[P1] Contribution graph keyboard-inaccessible + not the recognizable GitHub calendar. Cells are aria-hidden divs; auto-fill square grid not weeks×7. Fix: focusable buttons / hidden summary; grid-flow-col columns of 7 + horizontal scroll. Command: adapt.

[P2] "Warm editorial" undercut by mono-set prose. About/Contact paragraphs in JetBrains Mono read clipped. Fix: route prose to warm sans, keep mono for labels/prompts/chips. Command: typeset.

[P2] External fetch failure shows false "0". null data → total 0 → "0 contributions in the last year" with no error state. Fix: distinguish failed from zero; fallback link to GitHub. Command: harden.

## Persona Red Flags
